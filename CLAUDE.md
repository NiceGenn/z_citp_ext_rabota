# CLAUDE.md — правила проекта

## Что это

Chrome-расширение **«ЦИТП Заявка»** (Manifest V3, боковая панель) для формирования
заявок на регистрацию субъектов ЭП в системах **АЦК-Финансы** и **АЦК-Планирования**.
Загружает сертификаты `.cer`, ищет пользователей в базе АЦК (`.xlsx`), заполняет
Word-шаблон и упаковывает DOCX + сертификаты в архив.

Расширение самодостаточное: чистый JS + ES-модули, вендорный `lib/jszip.min.js`,
DOCX-шаблон встроен в `popup-data.js` (base64). Шага транспиляции нет — «сборка»
означает лишь упаковку загружаемой папки в zip.

## Структура

```
sources/citp-zayavka/   ← ИСХОДНИКИ. Все правки только здесь. = загружаемое расширение
releases/               ← ВЫХОД: citp-zayavka_v<версия>.zip. Руками НЕ править!
tools/build-release.sh  ← единственный способ обновить releases/
tools/gen-icons.js      ← dev-утилита генерации иконок (в релиз не входит)
docs/                   ← РУКОВОДСТВО.md (инструкция), ЧТО_НОВОГО.md (changelog)
MEMORY.md               ← память проекта: решения, состояние, ссылки
```

## Железные правила

1. **Правим только `sources/citp-zayavka/`.** Это единственный источник правды.
2. **`releases/` руками не трогаем.** Единственный способ обновить — запустить
   `tools/build-release.sh`. Zip'ы в `releases/` — сгенерированный артефакт.
3. **Версию поднимаем в `sources/citp-zayavka/manifest.json`** перед сборкой.
   Это единственный источник версии (её же читает и сам код расширения).
4. **Новую версию описываем в `docs/ЧТО_НОВОГО.md`.**
5. В релизный zip идёт **только чистое расширение** — без .md-доков и dev-утилит.

## Как собрать релиз

```bash
bash tools/build-release.sh        # → releases/citp-zayavka_v<версия>.zip
```

Скрипт читает `version` из manifest, кладёт `manifest.json` в корень архива,
исключает `*.md` и ОС-мусор. Прежние версии в `releases/` сохраняются.

**Всегда после сборки давать ссылку на релиз** в ответе — на zip в GitHub на
текущей ветке (owner/repo/ветка берём из `git remote`/текущей ветки):

```
https://github.com/<owner>/<repo>/blob/<branch>/releases/citp-zayavka_v<версия>.zip   ← страница файла
https://github.com/<owner>/<repo>/raw/<branch>/releases/citp-zayavka_v<версия>.zip    ← прямое скачивание
```

## Как проверить расширение в браузере

1. `browser://extensions/` (Яндекс) или `chrome://extensions/`.
2. Включить «Режим разработчика».
3. «Загрузить распакованное расширение» → указать папку `sources/citp-zayavka/`.

## Ключевые модули (`sources/citp-zayavka/js/`)

- `state.js` — общее состояние (база АЦК, шаблоны).
- `x509-parser.js` — разбор сертификатов X.509 (ArrayBuffer).
- `xlsx-parser.js` — чтение базы АЦК из `.xlsx` (лист «АЦК», 5 колонок) + нормализация систем.
- `matcher.js` — сопоставление ФИО из сертификата с базой (нечёткий поиск, Левенштейн).
- `docx-generator.js` — генерация DOCX по шаблону (поиск мест вставки по ключевым словам, не по индексам строк).

`popup.js` — только логика UI. `background.js` — открытие как side panel (Chromium 114+)
или как окно (старые браузеры / Яндекс).
