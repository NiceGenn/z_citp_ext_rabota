# История версий: Расширение ЦИТП Заявка

---

## v2.4.0 — 09.04.2026

### Новые возможности
- **Красная строка в заявке:** строки с пользователями, которые не найдены в базе АЦК
  («НЕ НАЙДЕН»), теперь выделяются красным фоном в DOCX-документе — их легко заметить
  и исправить вручную.
- **Имя архива при одном сертификате:** если загружен один сертификат, архив называется
  так же, как переименованный файл сертификата (например,
  `Печенкин Владимир Вячеславович ДЛ 06.2027.zip`).

### Улучшения
- Секции «Роль субъекта / Действие» и «Наименование системы» в панели визуально выделены
  рамкой — как блок «Параметры».

## v2.3.0 — 09.04.2026

### Новые возможности
- **Умная фильтрация по системам:** галочки «АЦК-Финансы» / «АЦК-Планирования» теперь работают
  как фильтр — из базы берутся только записи для отмеченных систем.
- **Объединение систем в одну строку:** если один логин найден в нескольких выбранных системах
  с одинаковой ролью — в заявке пишется одна строка с «АЦК-Финансы и АЦК-Планирования».
- **Нормализация названий систем:** краткие варианты «Финансы» / «Планирование» в базе
  автоматически приводятся к полным «АЦК-Финансы» / «АЦК-Планирования».
- **Роль субъекта** теперь отображается как затемнённые чекбоксы (Руководитель / Бухгалтер)
  с подсказкой «Берётся из базы АЦК». Значение полностью определяется базой.

### Исправления
- Исправлен принцип выбора записи: ранее брался первый попавшийся результат — теперь
  возвращаются все подходящие, затем фильтруются по выбранным системам.

## v2.2.0 — 09.04.2026

### Новые возможности
- База АЦК теперь поддерживает **два новых столбца**: «Роль субъекта» (D) и «Система» (E).
  Один и тот же пользователь может иметь разные записи для разных систем.
- Роль и наименование системы берутся автоматически **из базы** для каждого найденного
  пользователя. Значения из полей формы используются как запасной вариант для ненайденных.

### Улучшения
- Добавлен футер в интерфейсе расширения: разработчик и дата сборки.
- Встроенная база АЦК временно отключена — будет заменена файлом в новом формате (5 колонок).
  До этого базу необходимо загружать вручную через кнопку «Загрузить базу АЦК».

## v2.1.0 — 07.04.2026

### Исправлены баги
- **Критично:** При формировании заявки с двумя и более сертификатами строки с данными могли быть случайно удалены из таблицы DOCX — документ выходил пустым или неполным. Исправлено.
- **Безопасность:** Имя загруженного `.cer` файла вставлялось в HTML без экранирования. Теперь имя файла всегда добавляется как текст.
- **Память:** При повторном нажатии «Сформировать» предыдущий Blob URL теперь корректно освобождается.

### Новые возможности
- Кнопка **`×`** у каждого сертификата в списке — удаляет только этот файл без перезагрузки панели.
- Кнопка **«Очистить всё»** — сбрасывает весь список сертификатов и скрывает результат.
- **Прогресс при обработке**: строка статуса показывает `Обработка 2 / 7…` при пакетной генерации.

### Улучшения
- База АЦК из встроенного файла загружается при открытии — кнопка сразу зелёная, пульсация останавливается.
- Поиск листа «АЦК» в `.xlsx` теперь нечувствителен к регистру и лишним пробелам (`«ацк»`, `«АЦК »` — всё работает).
- Если лист «АЦК» не найден в файле — кнопка базы показывает понятное сообщение об ошибке вместо молчаливого отказа.
- При нажатии «Написать письмо» с пустым полем e-mail — фокус переходит на поле, письмо не открывается.
- Версия расширения берётся из `manifest.json` автоматически — больше не дублируется в коде.
- Алгоритм поиска ФИО ускорен: нормализация ключей базы выполняется один раз при загрузке, а не при каждом сравнении.
- Переход на **Semantic Versioning** (MAJOR.MINOR.PATCH).

## v2.0 — 05.04.2026 (рефакторинг)

Мы успешно провели глубокую модернизацию кода расширения. Нашей главной задачей было улучшить поддерживаемость и надежность кодовой базы, сохранив при этом её первоначальную философию: **максимальная автономность, работа в браузере клиента и ноль тяжелых сторонних зависимостей**.

## Что было сделано

### 1. Переход на ES-Модули
Монолитный файл скрипта (менее 700 строк) был разбит на логические модули в новой директории `js/`:
* `state.js` — централизованное хранение состояния (база, шаблоны).
* `x509-parser.js` — изолированный парсер сертификатов X.509 (использует ArrayBuffer).
* `xlsx-parser.js` — модуль загрузки и чтения базы АЦК через нативные средства.
* `docx-generator.js` — генератор `.docx` документа с заявкой.
* `matcher.js` — алгоритм сопоставления пользователей из сертификатов с базой.

В корневом `popup.js` осталась только понятная логика пользовательского интерфейса (кнопки, чекбоксы и вывод статусов).

### 2. Динамический анализ DOCX (Уход от жестких индексов) 
В модуле `docx-generator.js` была переписана логика внедрения данных в шаблон:
* **Интеллектуальный поиск строк**: Вместо жесткой привязки к номерам строк таблицы, генератор теперь сканирует XML-структуру шаблона, находит ключевые слова (например, "Роль субъекта", "Серийный номер" или шаблон даты `«___» 20__ г.`).
* **Точная вставка**: Данные сертификатов вставляются строго под табличной шапкой.
* **Авто-очистка**: Заглушки, присутствующие в шаблоне, автоматически удаляются после генерации.
* *Выгода*: Теперь вы можете изменять дизайн самого шаблона `ЗаявкаЦИТП.docx` (добавлять абзацы, менять шрифт выше таблицы), и расширение всё равно найдет правильное место для вставки строк.

### 3. Нечеткий поиск пользователей (Алгоритм Левенштейна)
В модуле `matcher.js` интегрирован алгоритм интеллектуального сопоставления:
* **Расчет дистанции**: Алгоритм вычисляет расстояние Левенштейна между строками, что позволяет корректно находить пользователя в базе даже при опечатках в его фамилии или имени ("Иванов" ↔ "Иваов").
* **Умные штрафы**: Фамилия имеет приоритетный вес, а имя и отчество могут сопоставляться по инициалам. Модель анализирует длину строки и прощает до 2 опечаток в длинных фамилиях, предотвращая ложные склейки разных людей.

## Как использовать обновленную версию
Просто перезагрузите расширение в браузере (на странице справочника `chrome://extensions` нажмите кнопку "Обновить"). Расширение само подтянет новую модульную структуру.
